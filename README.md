# Zoom Transcript Downloader Extension

## Version

- `1.3.4`

## Changes in 1.3.4

- paginator now targets Zoom's specific next-page control:
  `button.btn-next[aria-label="Next page"]`
- save-all delay reduced from 2.0s to 1.5s between download triggers

## Important

Reload the unpacked extension in `chrome://extensions`, then refresh the Zoom page.
