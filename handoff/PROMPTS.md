# PROMPTS

## Standard prompt for a future LLM

Read `README.md`, `ARCHITECTURE.md`, `DECISIONS.md`, and all files under `handoff/` before making changes.

Approach this repo as a fragile browser automation project. Prefer minimal diffs. Preserve intended behavior unless explicitly changing it. Do not rewrite large areas for style alone. Verify assumptions against the actual code and, where possible, real Zoom DOM behavior. Be candid about uncertainty. If changing pagination, download tracking, or rename generation, update the relevant docs in the same commit.
