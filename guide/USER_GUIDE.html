Zoom Transcript Downloader User Guide

Version 2026.10 · guided workspace

Privacy and scope: Sign in directly on Zoom/SSO. The extension never asks for or stores your password. It scans metadata for the signed-in user's accessible lists, not company-wide. Transcript content is accessed only after you explicitly start an export.

Install

Install through the direct Chrome Web Store listing (may be private/unlisted). Edge can install Chrome Web Store extensions if allowed. For manual installation, extract the package, open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.

Connect, scan, review

  1. The extension-owned workspace opens on first installation. Reopen it from the extension toolbar button.
  2. Enter your organization's Zoom subdomain, then choose Recording transcripts and/or My Notes transcripts. The selection determines what can be exported later; it does not start export.
  3. Click Open Zoom and scan sources. The extension opens/reuses both Zoom lists in background tabs. Complete sign-in on Zoom/SSO if requested. Readiness waiting is bounded to two minutes; Stop cancels discovery.
  4. Discovery reads metadata only; no transcript text is exported or downloaded. Review both complete source lists. Incomplete scans block download.
  5. Recording/My Notes are kept in separate lists. Verified exact shared occurrence IDs produce reciprocal Also in badges; titles/numeric meeting IDs alone do not match. Missing associations remain uncertain, so exact unique cross-source total can be unknown. Availability is separate and may be unknown until export.

Export and results

  1. Select the sources to export and explicitly click Download selected transcripts.
  2. The selected sources run sequentially in inactive Zoom tabs. During active work, Zoom source pages show only a small centered read-only progress bubble; idle guided source pages show no downloader panel. Completion, Stop, and errors are reflected in the workspace. Keep the browser open and review saved, unavailable, failed, and remaining counts.
  3. If Action needed appears, sign in on the indicated Zoom tab and restart the affected source. The actionable requirement stays visible. Completed files are preserved. Source-list tabs may remain open for review/retry; only an extension-created terminal worker still on its source page may be closed. Stop prevents later exports; the current operation may finish or be canceled safely.

My Notes scope

My Notes export means transcript files available from note entries. It does not download note text, AI summaries, or other meeting documents. Some transcripts may be unavailable or have unknown permission until an export attempt.

Output and settings

Files go to browser Downloads, optionally under a configured subfolder, in a dated ZoomTranscripts-MMDDYYYY folder with separate Recordings and My Notes folders. Existing files are not overwritten; conflicts are uniquified. Legacy page-panel Settings control filename pattern (default {date} - {time} - {title}; tokens {date}, {time}, {title}, {meetingId}) and Downloads subfolder. Arbitrary absolute paths are not supported.

Failure and retry

A partial or stale inventory is not approved for export. Company/source target changes invalidate the review. Retry after sign-in/access/readiness issues; the extension does not claim automatic resume or per-item selection. Some failure states are reported rather than treated as success.

Legacy panel and older materials

The injected page panel remains an advanced/manual fallback, separate from the guided workflow. Instructions/screenshots describing Save all, Save page, or auto-opened panel refer to that older UI. This printable guide matches the current guided workflow. Older screenshots may depict the former recordings-only panel.

Validation limits

The 2026.10 baseline has 13 Node test files and 24 cases; these are mocked tests, not full live-browser acceptance. Inventory and custom rails have been checked live; native-wheel rail behavior and a fresh SSO-to-export acceptance run are not established here. Do not infer complete production acceptance from screenshots or test counts.
