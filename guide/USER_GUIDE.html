Zoom Transcript Downloader User Guide

Version 2026.11 · guided workspace

Privacy and scope: Sign in directly on Zoom or SSO. The extension never asks for or stores your password. It scans Recording and My Notes metadata accessible to the signed-in Zoom user, not an organization-wide account. Transcript content is accessed only after you explicitly start an export.

Install

Install through the direct Chrome Web Store listing (may be private or unlisted). Edge can install Chrome Web Store extensions if allowed. For manual installation, extract the package, open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.

Connect, scan, review

  1. The extension-owned workspace opens on first installation. Reopen it from the extension toolbar button.
  2. Enter your organization's Zoom subdomain, then choose Recording transcripts and/or My Notes transcripts for download. Selection does not start an export. Scanning reads metadata from both source lists; only selected sources with complete scans may be exported.
  3. Click Open Zoom and scan sources. The extension opens or reuses both Zoom source tabs. Complete sign-in on Zoom or SSO if requested. Readiness waiting is bounded to two minutes; Stop cancels discovery.
  4. Discovery reads source-list metadata only. It does not export transcript text or download files. Review the source status and inventory. An incomplete source cannot be included in an export; uncheck it or retry it from Review. Completed source scans are retained.

Understand the inventory and duplicate handling

Recording and My Notes remain in separate lists. Only a verified exact shared occurrence ID establishes an association and may produce reciprocal Also in My Notes or Also in Recordings badges. A title or numeric meeting ID alone is not a match. Missing associations remain uncertain or unknown, so the exact unique-meeting count can be unknown. Availability is separate and may be unknown until export.

Avoid duplicate meetings across sources is on by default. When both sources are selected, Recording is tried first for an exact shared occurrence ID. The matching My Notes transcript is skipped only after a successful Recording save. If Recording is unavailable or fails for that item, My Notes is tried instead. Sign-in or browser prompts can pause the batch before fallback. Turn the setting off to download both copies. The review estimate counts exact matches only and is conditional on successful Recording saves.

Export and results

  1. Select one or both fully scanned sources and explicitly click Download selected transcripts. If none is selected, the workspace asks you to select at least one.
  2. Selected sources run sequentially. Active Zoom source pages show a centered progress bubble with live counts and a Stop download button. Completion, Stop, and errors are reflected in the workspace. Keep the browser open and review saved, duplicates avoided, unavailable, failed, and remaining counts.
  3. If Action needed appears, follow the action shown for that source. Sign in only if requested; if a browser save dialog is outstanding, close or cancel it before retrying. Completed files are preserved. Source-list tabs may remain open for review and retry; only an extension-created terminal worker still on its source page may be closed. Stop prevents later exports; the current operation may finish or be canceled safely.

Output and saved settings

Files go under browser Downloads in a dated ZoomTranscripts-MMDDYYYY folder, optionally preceded by a configured subfolder. Separate Recordings and My Notes folders are used. Existing files are not overwritten; filename conflicts are uniquified. Missing dates or times use unknown-date or unknown-time in filenames.

Collapsed Download settings sections on Connect and Review control the filename pattern, Downloads subfolder, Recording meeting-ID suffix, and cross-source duplicate avoidance. Save or discard edits before scanning or exporting. Review shows the saved effective filename examples and destinations used for export. Default pattern: {date} - {time} - {title}; tokens are {date}, {time}, {title}, and {meetingId}. Recording meeting IDs are optional. Adding {meetingId} enables the ID checkbox; unchecking it removes the token. My Notes filenames do not include meeting IDs. Empty optional tokens and adjacent separators are omitted. Arbitrary absolute destinations are not supported.

Browser save dialogs, stopping, and warnings

For an unattended batch, open browser Settings > Downloads and turn off Ask where to save each file before downloading; turn it back on afterward if you prefer. The extension cannot verify this preference or reliably detect a browser save dialog. If a download request does not respond within its bounded wait, the affected source stops and the workspace reports that a save dialog may need attention. Check the browser and Downloads before retrying.

During a scan, Stop cancels discovery without beginning export. During export, Stop prevents later exports; the current operation may finish or be canceled safely. Completed files remain.

A warning appears after three minutes without export-count progress. Long bounded Zoom or network waits can be normal. The warning is informational only: it does not stop or restart the export. Check the Zoom source tab or Downloads, and choose Stop only if you want to end the export.

Retry and failures

Retry an incomplete scan from Review; partial rows cannot be exported as a complete inventory and completed source scans are retained. Export retry is source-level, not limited to failed rows. It may save already successful items again as additional uniquely named copies, so review the warning before retrying. Unavailable entries may be skipped. Authentication, rate limits, changed Zoom behavior, and ambiguous failures are reported rather than treated as success.

My Notes scope and legacy panel

My Notes export means transcript files available from note entries. It does not download note text, AI summaries, or other meeting documents. The older injected page panel remains an advanced/manual workflow, separate from the primary guided workspace. Older instructions or screenshots describing Save all, Save page, or an automatically appearing panel refer to that legacy UI.

Troubleshooting

  • Workspace did not open: use the extension toolbar button. For manual installs, reload the extension in the browser Extensions page.
  • Sign-in/access required or readiness timed out: sign in directly on the indicated Zoom or SSO tab and retry.
  • A source scan is incomplete: use that source's Retry action on Review. A completed scan is retained; partial rows cannot be exported.
  • An export reports errors: review per-source counts and the retry warning. Confirm Zoom access and selected date range, then retry the source needing attention.
  • Files not where expected: check Downloads, the configured subfolder, dated folder, and separate source folders.
  • Zoom changed: the extension depends on Zoom's pages, pagination, authentication, and export behavior. Reload or update and retry; report the source and failure stage without transcript content or authentication data.

Supported browsers: Google Chrome and Microsoft Edge. Before sharing debug details or screenshots, check for meeting metadata, URLs, and other sensitive information.
