Zoom Transcript Downloader

Quick Start · guided workspace baseline 2026.10.1

Privacy: sign in on Zoom/SSO. The extension never asks for or stores your password. Scanning reads accessible transcript-list metadata only; transcript export begins only after you review and explicitly start a download.

1. Install and connect

  1. Install from the Chrome Web Store direct listing (possibly private/unlisted). Edge can install it if other-store extensions are allowed.
  2. The extension-owned workspace opens on first install. Later, open it using the extension toolbar button.
  3. Enter your organization's Zoom subdomain; do not enter a password. Choose Recording transcripts, My Notes transcripts, or both.

2. Scan and review

  1. Choose Open Zoom and scan sources. Both Zoom lists open/reuse in background tabs; sign in directly on Zoom/SSO if prompted.
  2. The scan reads metadata only and does not export/download transcript content. Readiness waiting is bounded to two minutes. Stop cancels discovery.
  3. Review each source status. My Notes completes when the authenticated list API returns an empty nextPageToken and the collected metadata count matches. Partial rows remain reference-only and cannot be exported as complete. Uncheck incomplete sources to proceed with a fully scanned source. Exact shared identifiers may show reciprocal association badges; missing associations remain uncertain.

3. Download

  1. Select only fully scanned source(s) and explicitly click Download selected transcripts. A user-assisted Edge acceptance run completed exports for both selected sources, with per-source results matching the files saved in their dated Recordings and My Notes folders.
  2. Review per-source saved, unavailable, failed, and remaining results. Active Zoom source pages show a centered progress bubble with live counts and a Stop download button; idle guided pages show no downloader panel. Action needed means sign in on Zoom and restart that source; completed files remain.
  3. Files are saved in Downloads under a dated folder with separate Recordings and My Notes subfolders. Existing files are preserved; conflicts get unique names. Chrome, Stop during active export, and rate-limit/expiry behavior remain untested.

My Notes refers to transcript files—not note text, AI summaries, or other meeting documents. The scope is the signed-in user's accessible items, not organization-wide.
