Zoom Transcript Downloader

Quick start guide for version 2026.08

What it does

This extension saves Zoom transcript text files directly with clean final names such as 2026-08-14 - 1601 - Google CEP Setup and Deep Dive.txt.

Use It

  1. Open your Zoom transcript page in Edge or Chrome.
  2. Click the Zoom Transcript Downloader extension icon.
  3. If needed, click the gear icon to review settings.
  4. Click Save all available.
  5. Let the extension finish scanning all pages, then saving the transcripts.
Expected behavior: the extension uses a two-pass workflow. It scans first so it can plan the final filenames, then it goes back and downloads the files in order.

Recommended Settings

Filename pattern

Recommended default:

{date} - {time} - {title}

Save folder inside Downloads

Choose a clean subfolder under your normal Downloads folder.

Example: Work/Zoom

Include meeting ID

Usually leave this off. Turn it on only if you want the meeting ID added to every filename.

What You Should See

  • The extension resets to page 1.
  • It scans every transcript page.
  • It then downloads available transcripts one by one.
  • Unavailable or disabled transcript rows are skipped.
  • Finished files appear in your Downloads subfolder with the final filename already applied.

Troubleshooting

  • If nothing happens, refresh the Zoom transcript page and try again.
  • If the run stops early, turn on Show debug and retry.
  • If Zoom’s list changes during the run, refresh and start over.
  • If you want help or repo details, click the ? icon in the extension.
