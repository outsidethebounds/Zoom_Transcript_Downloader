Zoom Transcript Downloader

Quick start guide for version 2026.08

Start here

This guide is focused on getting to the correct Zoom transcript page first, then saving transcripts with the extension.

Get To The Right Zoom Page

  1. Make sure you are logged into your Zoom account in Edge or Chrome.
  2. Go to https://your_company.zoom.us/recording/meeting/transcript.
  3. Wait for the Recordings and Transcripts page to load.
  4. The extension window should automatically pop up in the upper-right corner of the page.
  5. If it does not pop up, click the Zoom Transcript Downloader extension icon manually.

Example transcript page with the extension open. Sensitive meeting details in this example have been hidden.

Tip: make sure you are on the Transcripts tab, not Cloud recordings or another Zoom section.

Save Your Transcripts

  1. Review the count shown in the extension header.
  2. If needed, click the gear icon to review settings first.
  3. Click Save all available.
  4. Let the extension finish scanning all pages, then saving the transcripts.
Expected behavior

The extension uses a two-pass workflow on purpose. It scans all transcript pages first so it can plan clean final filenames, then it goes back and saves the files in order.

Recommended Settings

Filename pattern

Recommended default:

{date} - {time} - {title}

This produces filenames like 2026-08-14 - 1601 - Google CEP Setup and Deep Dive.txt.

Save folder inside Downloads

Choose a clean subfolder under your normal Downloads folder.

Example: Work/Zoom

Include meeting ID

Usually leave this off. Turn it on only if you want the meeting ID appended to each filename.

What You Should See

  • The extension resets to page 1 before it begins the save run.
  • It scans every transcript page.
  • It then downloads available transcripts one by one.
  • Unavailable or disabled transcript rows are skipped automatically.
  • Finished files appear in your Downloads subfolder with the final filename already applied.

Troubleshooting

  • If the extension does not appear, refresh the Zoom transcript page and click the extension icon manually.
  • If nothing happens after you click Save all available, refresh the page and try again.
  • If the run stops early, turn on Show debug and retry.
  • If Zoom’s list changes during the run, refresh the page and start over.
  • If you need help or repo details, click the ? icon in the extension.
