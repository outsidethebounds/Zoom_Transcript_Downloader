Zoom Transcript Downloader

Quick Start · 2026.11 · guided workspace

Privacy and scope: Sign in directly on Zoom or SSO. The extension never asks for or stores your password. It scans metadata from Recording and My Notes lists accessible to the signed-in user, not an organization-wide account. Transcript content is accessed only after you explicitly start an export.

1. Install and connect

  1. Install from the Chrome Web Store direct listing (possibly private or unlisted). Edge can install it if extensions from other stores are allowed.
  2. The extension-owned workspace opens on first install. Later, open it using the extension toolbar button.
  3. Enter your organization's Zoom subdomain; do not enter a password. Choose Recording transcripts, My Notes transcripts, or both for a future export. Scanning reads metadata from both source lists regardless of export selection; selection controls which complete sources can be downloaded.

2. Configure, scan, and review

  1. Open the collapsed Download settings section on Connect or Review to set the filename pattern and optional folder inside Downloads. Save or discard edits before scanning or exporting. Review shows saved filename examples and destinations for both sources.
  2. Avoid duplicate meetings across sources is on by default. When both sources are selected, only exact shared occurrence IDs are matched and Recording is tried first. My Notes is skipped only if Recording saves successfully; My Notes is tried if Recording is unavailable or fails for that item. Sign-in or browser prompts can pause the batch before fallback. Turn the setting off to download both copies. Titles or numeric meeting IDs alone do not match; missing IDs remain uncertain.
  3. Choose Open Zoom and scan sources. The Zoom source tabs open or are reused. Sign in directly on Zoom or SSO if prompted. Scanning reads metadata only; it does not export transcript content. Readiness waiting is bounded to two minutes. Stop cancels discovery.
  4. Review each source status. An incomplete source cannot be included in an export; uncheck it or retry it from Review. A completed source scan is retained. Verified shared occurrence IDs may show reciprocal association badges.

3. Download and results

  1. For an unattended batch, open browser Settings > Downloads and turn off Ask where to save each file before downloading; restore it afterward if you prefer. A browser save prompt may still need attention.
  2. Select one or both fully scanned sources and click Download selected transcripts. If none is selected, select at least one to continue. Active Zoom source pages show a centered progress bubble with live counts and a Stop download button. Completed files remain.
  3. Review per-source saved, duplicates avoided, unavailable, failed, and remaining counts. Results show the destination recorded for the run. Files are under Downloads in a dated ZoomTranscripts-MMDDYYYY folder with separate Recordings and My Notes folders.
  4. Export retry is source-level and can save successful items again as additional uniquely named copies. Review the warning before retrying. A warning after three minutes without export-count progress is informational only; it does not stop or restart the export. Long Zoom or network waits can be normal.

Missing dates or times use unknown-date or unknown-time in filenames. Existing files are preserved; filename conflicts receive unique names.
