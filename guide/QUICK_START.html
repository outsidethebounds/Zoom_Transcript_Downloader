Zoom Transcript Downloader

Quick Start · 2026.10.2 · guided workspace

Privacy: sign in on Zoom/SSO. The extension never asks for or stores your password. Scanning reads accessible transcript-list metadata only; transcript export begins only after you review and explicitly start a download.

1. Install and connect

  1. Install from the Chrome Web Store direct listing (possibly private/unlisted). Edge can install it if other-store extensions are allowed.
  2. The extension-owned workspace opens on first install. Later, open it using the extension toolbar button.
  3. Enter your organization's Zoom subdomain; do not enter a password. Choose Recording transcripts, My Notes transcripts, or both for download. Scanning checks both lists; selection controls which completed sources can be downloaded.

2. Configure, scan, and review

  1. Set the filename pattern and optional folder inside Downloads. The Recording ID checkbox adds meeting IDs when available. Using {meetingId} in the pattern enables the checkbox; unchecking it removes the token. My Notes filenames do not contain IDs, and empty tokens do not leave extra separators.
  2. Save or discard settings edits before scanning or exporting. After scanning, Review shows the saved effective filename examples and destinations.
  3. Choose Open Zoom and scan sources. Both Zoom lists open/reuse in background tabs; sign in directly on Zoom/SSO if prompted. Scanning reads metadata only and does not export transcript content. Readiness waiting is bounded to two minutes. Stop cancels discovery.
  4. Review each source status. My Notes completes when the authenticated list API returns an empty nextPageToken and the collected metadata count matches. Partial rows cannot be exported as a complete inventory. Use the incomplete source's Retry action to rescan it; a completed source scan is retained. Exact shared identifiers may show reciprocal association badges; missing associations remain uncertain.

3. Download and results

  1. For an unattended batch, open browser Settings > Downloads and turn off Ask where to save each file before downloading; restore it afterward if you prefer. The workspace repeats this reminder beside the destination. A browser save prompt may still need attention.
  2. Select one or both fully scanned sources and click Download selected transcripts. If none is selected, select at least one to continue. Active Zoom source pages show a centered progress bubble with live counts and a Stop download button; completed files remain.
  3. Review per-source saved, unavailable, failed, and remaining results. Results show the original dated destination used for each source, including after reopening the workspace. Older runs without a saved path show the destination as unavailable.
  4. Export retry is source-level and can save successful items again as additional uniquely named copies. Review the warning before retrying. If a download times out, check and close or cancel any outstanding browser save dialog or Downloads item before retrying. Files stay under Downloads in the dated folder and separate Recordings and My Notes folders.

My Notes refers to transcript files—not note text, AI summaries, or other meeting documents. The scope is the signed-in user's accessible items, not organization-wide.
